Fábrica de Vídeos

Ferramenta pessoal de Bruno Marchese · Personal tool by Bruno Marchese

Português

A Fábrica de Vídeos é uma ferramenta de uso pessoal, executada no computador do próprio autor, que automatiza a criação dos vídeos do canal de histórias de terror O que te Assusta (roteiro, narração, imagens e edição).

Esta página existe para identificar o aplicativo junto ao TikTok for Developers e à API de postagem de conteúdo do TikTok. A ferramenta usa o login do TikTok somente para enviar, como rascunho, vídeos criados pelo próprio autor para a própria conta do autor. Não é um serviço aberto ao público e não tem cadastro de usuários.

English

Fábrica de Vídeos ("Video Factory") is a personal tool that runs on the author's own computer and automates the production of videos for the horror-story channel O que te Assusta (script, narration, images and editing).

This page identifies the app for TikTok for Developers and the TikTok Content Posting API. The tool uses TikTok Login only to upload, as a draft, videos created by the author to the author's own account. It is not offered to the public and has no user sign-up.
